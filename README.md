# 📝 Task Manager

A modern, highly interactive, and responsive Task Manager application built to demonstrate advanced UI/UX principles and solid Vanilla JavaScript architecture.

[![Live Demo](https://img.shields.io/badge/Demo-Live_Preview-4f46e5?style=for-the-badge)](https://allahverdi-dev.github.io/task-manager/)

## ✨ Features

- **Object-Oriented JavaScript:** Clean, maintainable, and class-based architecture.
- **LocalStorage Integration:** Tasks persist across browser sessions.
- **Advanced UI/UX:** Glassmorphism elements, custom checkboxes, and smooth CSS animations.
- **Dynamic Filtering:** Instantly sort between 'All', 'Active', and 'Completed' tasks.
- **Responsive Design:** Flawless experience across desktop, tablet, and mobile devices.
- **Accessibility (a11y):** Semantic HTML tags, aria-labels, and SR-only inputs.
- **XSS Protection:** Built-in HTML escaping to prevent Cross-Site Scripting attacks.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure
- **CSS3:** Custom properties (variables), Flexbox, Animations
- **Vanilla JavaScript:** ES6+ features, Event Delegation, DOM Manipulation
